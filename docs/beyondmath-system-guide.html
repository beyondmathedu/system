4. 各頁面邏輯說明

以下按實際使用順序，說明每個主要頁面做什麼、資料從哪來、誰可以改。

① Home 提醒板

路徑：/home · 僅 Admin

  • 用途：登入後總覽，顯示待辦提醒（補堂、未 tick 出席、生日等）。
  • 邏輯：從 Supabase 讀取所有學生課堂狀態，計算哪些需要跟進。
  • 操作：點提醒可跳轉到對應學生或課堂頁面處理。

② 學生名單

路徑：/students · 僅 Admin

  • 用途：管理學生基本資料（姓名、年級、學校、Email、電話等）。
  • 邏輯：資料存在 Supabase students 表；搜尋／篩選 Active／Inactive。
  • Portal 欄：可「開 Portal 帳號」、「手動重設密碼」、「同步電郵」。
  • 重要規則：Portal 密碼預設 = 8 位聯絡電話；儲存學生資料時會自動同步密碼／電郵。
  • Inactive 學生：暫停登入 Portal，可設定復課日期。

③ 學生課堂 Hub

路徑：/students/{學號}/lessons · Admin 可編輯；Student 只看自己

  • 用途：學生課堂入口，顯示 Current Settings（每週課堂時間）及年度連結。
  • 邏輯：從 active schedule version 讀取每週 Regular 設定。
  • Student Portal：登入後只看自己的 Hub，不能改任何資料。

④ 學生年度課堂頁（核心排期）

路徑：/students/{學號}/lessons/{年份} · 僅 Admin 可編輯

  • 用途：管理該學生整年課堂：Regular、Extra、補堂、Hide、出席 tick。
  • 資料來源：Schedule records（每週規則）+ student_lessons_year_state（出席、override、補堂記錄）。
  • Regular：每週固定課堂，由 Schedule grid 產生。
  • Hide date：隱藏某次 Regular，不刪除規則。
  • Extra：加一堂一次性課堂。
  • Reschedule 補堂：原日期變 Cancel，新日期上課。
  • Leave／Pending makeup：請假待補，Home 會提醒。
  • Delete 補堂：刪除後 Regular 恢復 Regular；Extra 移動後刪除會恢復原位。
  • 注意：導師 Tutor 和 Lesson summary 建議在 Room 課室頁改（按日期儲存）。

⑤ 費用記錄

路徑：/students-lesson-time-fee-record · 僅 Admin

  • 用途：每月學生堂數、學費、期初結餘、價目設定。
  • 邏輯：堂數通常由出席記錄計算；Admin 可手動調整及提交。
  • 資料：student_monthly_fee_records 等 Supabase 表。

⑥ Daily Timetable 每日課表

路徑：/daily-time-table · Admin 可改樣式；iPad 只讀

  • 用途：一日內所有課室、所有時段一覽。
  • 邏輯：聚合各學生 schedule + 當日 override，按課室／時間排列。
  • Admin：可改表格顏色、樣式；看到完整備註。
  • 共用 iPad：只讀；備註會隱藏；可點進課室頁記出席。
  • 預設：iPad 登入後落在此頁（今日日期）。

⑦ Room 課室頁（出席／導師／Summary）

路徑：/rooms/{slug} · Admin 全改；iPad 僅今天

  • 用途：單一課室在一段時間內的所有課堂列表。
  • 資料來源：所有在該課室上課的學生 schedule 聚合而成。
  • 期間：Admin 可切 Today／This Week／This Month；iPad 預設 Today，亦可切其他期間但只能改今天。
  • 出席 Attendance：tick 後寫入該學生 year state；iPad 僅香港「今日」可 tick。
  • 導師 Tutor：只限 Admin 改；改動會寫入該日 override。
  • Lesson summary：堂後小結；iPad 僅今日可改。
  • 五個課室 slug：b、m-qian、m-hou、hope、hope-2

⑧ 導師管理 Teacher Records

路徑：/teacher · 僅 Admin

  • 用途：管理導師資料（T001…）、費率、顏色、MPF、狀態。
  • 邏輯：資料在 tutors、tutor_rates 表；用於課表顯示導師顏色及月薪計算。
  • Tutor 登入密碼：選定導師後，在頁底「Tutor 登入密碼」區重設（須已綁定 Supabase Auth）。
  • 共用 iPad 帳號：即 hk6896554@gmail.com，密碼亦在此重設。
  • 注意：此頁管理的是「導師資料」，不是課室 iPad 的日常操作入口。

⑨ 導師月薪記錄

路徑：/tutor-monthly-lesson-record · 僅 Admin

  • 用途：按導師計算每月授課堂數及薪金。
  • 邏輯：從出席記錄 + 導師費率計算；可設定 MPF、第一席位金額等。

⑩ Regular Class Timetable

路徑：/regular-class-timetable · 僅 Admin

  • 用途：以課室為單位看 Regular 時段配置（非每日動態）。
  • 邏輯：顯示各課室固定 Regular 時段，供行政參考。
